# AUDIO_BRIEF — звук «Лунного улова»

> Версия 1.0 · Э0.5. Источник правды для музыки, эмбиента и SFX. Партитуры и сборка — `tools/audio/`, реестр — `tools/audio/audio_assets.json`. Основа — GDD §19, PLAN §2.8, решения D-011, D-015, D-030…D-034.

## 1. Вайб и границы
- **Настроение:** тёмный уют. Dark ambient (длинные пэды, дроны, шум плёнки, большая реверберация) плюс dungeon synth (простые «средневековые» мотивы на дешёвом синтезаторе, колокольчики, арфа). Ночь у воды: тихо, немного тревожно, но безопасно.
- **Референсы — только словами** («вайб oneheart», «вайб hide cs01»). Чужие треки не семплируем, не цитируем мелодии и не повторяем узнаваемые ходы. Всё звучание строится синтезом с нуля (numpy/scipy), записанных звуков в проекте нет.
- **Для всех возрастов:** без скримеров, резких громких звуков, «зловещих» хоров и религиозных песнопений. Хор — нейтральные гласные «о / а / у».
- **Звук не должен утомлять.** Сессия длится 5–20 минут, а тапы и забросы слышны сотни раз. Поэтому частые звуки короткие и тихие, у повторяющихся есть варианты, музыка не громче −18 LUFS.

## 2. Музыкальный язык
- **Лад и темп:** ре дорийский, 64 BPM, 4/4. Один такт = 3,75 с. Дорийская ступень — си (B) в аккорде G, на ней держится «средневековый» привкус.
- **Гармония «Лунного берега»:** аккорд на 2 такта, цикл 32 такта = 120 с:
  `Dm G Dm C | F C G Am | Dm G Dm C | F G Am Asus`.
- **Фразы мелодии** — по 8 тактов (30 с): такты 1, 9, 17, 25. В тактах 31–32 мелодия молчит, это вдох перед повтором петли.
- **Всё, что звучит поверх трека в любой момент** (слой напряжения, фразы поимки), стоит на D и A, иногда на E. Такие ноты ложатся на любой аккорд прогрессии, поэтому их не нужно подстраивать под текущий такт (D-031).
- Финал легендарной фразы — пустая квинта D–A–D, как в средневековой каденции: без терции нет спора с минором или мажором под ней.

## 3. Палитра инструментов (`tools/audio/synth.py`)
| Инструмент | Как сделан | Где |
|---|---|---|
| Пэд | 3 расстроенные пилы (supersaw, ±7 центов) → ФНЧ 550–1250 Гц, атака 2,2 с, спад 4 с | основа |
| Дрон | синус + треугольник D2, синус A2, пила D3 за ФНЧ; «дыхание» громкости с периодом 15 с | основа |
| Хор | пила с вибрато → форманта «о» / «а» / «у» | основа (2-я половина), легендарная, лунная |
| Колокольчики | FM (отношение 3,5 / 2 / 1,41 / 2,76), спад 0,2–4,5 с | везде |
| «Касио»-флейта | пульс 25 % + треугольник, дыхание из шума, задержанное вибрато, 12 бит / дециматор ×2 | мелодия, редкая и легендарная фразы |
| Арфа | щипок (Karplus–Strong), восьмые по аккорду | мелодия (такты 9–16, 25–30) |
| «Сердце» / литавры | синус с падающей частотой + 2-я гармоника (слышно и в телефоне) + щелчок | напряжение, легендарная |
| Бас-пульс | пила + пульс 30 % → ФНЧ 520 Гц, мягкий клиппер, восьмыми | напряжение |
| Тремоло струнных | supersaw A4 + D5 → полоса 300–2300 Гц, тремоло 32-ми | напряжение |
| Плёнка | шум −54 dBFS, детонация (wow 0,5 Гц ±5 центов, flutter 6,4 Гц ±1 цент) | основа, все слои |
| Реверберация | синтетическая ИК (шум с экспоненциальным спадом, демпфирование ВЧ), RT60 2,2–5,5 с | везде |

Музыка нарочно тёмная: выше 10 кГц почти ничего нет. Так звучит «старая плёнка», и в телефонных динамиках ничего не режет слух.

## 4. Слои музыки и логика AudioDirector (D-030)
Трек локации — три бесшовные петли. **Все слои стартуют одновременно и звучат всегда.** AudioDirector меняет только громкость (твины `volume_linear`), поэтому слои никогда не расходятся по фазе.

| Слой | Длина | Что внутри | Когда слышен |
|---|---|---|---|
| `base` | 32 такта = 120 с | пэд, дрон, редкие колокольчики, хор во 2-й половине, шум плёнки | всегда на локации |
| `melody` | 32 такта = 120 с | флейта, арфа, эхо, колокольчики | после спокойствия, только с границы фразы |
| `tension` | 8 тактов = 30 с (¼ петли) | бас-пульс, «сердце», тремоло | вываживание |

Правила смешивания (вход мелодии, подсечка и поимка — как в `demo_scenario`; все числа уточняются на Э6.1):
- **Вход мелодии:** после 20 с без действий директор ждёт ближайшую границу фразы (0 / 30 / 60 / 90 с позиции петли) и поднимает громкость за 2 с, начиная за 1 с до границы. На практике мелодия входит через 20–50 с спокойствия.
- **Подсечка:** мелодия уходит за 2 с, напряжение входит за 0,8 с.
- **Поимка:** напряжение уходит за 1,5 с; петли музыки приглушаются до 0,4 за 0,15 с, держатся так, пока звучит фраза поимки, и возвращаются за 2 с.
- **Срыв:** напряжение уходит за 1 с, мелодия не возвращается до следующего «спокойствия».
- **Смена локации:** кроссфейд треков 1,5–2 с через шторку перехода.

## 5. Луна, события, локации
- **Фаза луны** (GDD §19): в полнолуние пэд светлее, в новолуние темнее и ниже. В партитурах уже есть параметр `brightness` (срез фильтров пэда, баса и струнных). Варианты — отдельные рендеры слоя `base` через поле `params` в реестре, директор переключает их кроссфейдом при смене фазы. Делается на Э6.2.
- **Багровая луна:** свой вариант трека. Гармония и сетка те же, чтобы фразы поимки подходили без правок, меняется тембр: глуше пэд, больше хора, без колокольчиков. Э6.2.
- **Ров Вельмора:** свой трек на той же сетке 64 BPM, чтобы фразы поимки и напряжение подходили без правок. Эмбиент рва — капель, далёкие всплески, сова. Э6.2.

## 6. Шины, громкость, приглушение (D-032)
**Шины Godot:** `Master` → `Music`, `Ambience`, `SFX`, `UI`. В Web (Sample playback) эффекты шин недоступны, поэтому приглушение и кроссфейды — только твины громкости (D-011).

**Громкость шин по умолчанию** (линейная; настройки игрока умножаются на неё):

| Шина | По умолчанию | дБ |
|---|---|---|
| Music | 0,7 | −3,1 |
| Ambience | 0,8 | −1,9 |
| SFX | 1,0 | 0 |
| UI | 0,8 | −1,9 |

**Нормализация при сборке** (`build_audio.py`, потолок −1 dBTP):
- **Музыка — группой:** сумма `base + melody` = −18 LUFS. Один общий коэффициент для всех трёх слоёв, чтобы их баланс оставался таким, как в партитуре. Пик суммы всех трёх слоёв не выше −1 dBTP.
- **Фразы поимки** растут с редкостью: обычная −21, необычная −20, редкая −19, лунная −18, легендарная −17 LUFS.
- **Эмбиент:** −27 LUFS. Он фон и не должен спорить с музыкой.
- **SFX — по пику:** всплеск и поклёвка −3 dBFS, заброс −5, катушка −7, тап UI −10. Короткие звуки по LUFS измеряются плохо, пик предсказуемее.
- **Совместимость с моно** (динамик телефона): при сведении в моно трек теряет не больше 3 LU. Сейчас основа −1,8, лунная фраза −1,9, эмбиент −2,8, остальное не больше 0,5.

## 7. Эмбиент
Отдельная петля 60 с на шине `Ambience`, с музыкой не синхронизирована.
- **«Лунный берег»** (`amb_shore_night`): накат волн и шипение пены (7–9 волн за петлю, разная панорама), плеск о сваи, ветер из трёх полос шума с порывами, три сверчка на разной высоте и дистанции, два тихих скрипа досок.
- Всё, что модулируется во времени (порывы, огибающие волн), уложено в петлю целым числом периодов, поэтому стыка не слышно.

## 8. SFX (D-034)
- **Моно, 44,1 кГц.** Стерео-позицию даёт игра (`AudioStreamPlayer2D` или панорама), если нужно.
- **Варианты:** 2–3 рендера с разным `seed` (немного другие высота, время и капли) плюс случайный `pitch_scale` ±4 % в игре. Один и тот же звук два раза подряд не повторяется.
- **Катушка** — одна бесшовная петля 2 с. Скорость намотки = `pitch_scale` 0,9–1,2 (быстрее мотаешь — выше и чаще треск).
- **Отклик:** звук начинается в первые 10 мс файла, тишины в начале нет. Исключение — лунная фраза: перед ней 1,4 с «вдоха» (обратный колокол), а мгновенный отклик в этот момент даёт всплеск поимки.
- **Пробный набор Э0.5:** заброс ×3, всплеск поплавка ×3, поклёвка ×2, катушка (петля), тап UI ×3. Полный список GDD §19 — Э6.3.

## 9. Технические правила
- **Формат:** OGG Vorbis, 44,1 кГц. Музыка, эмбиент и фразы — стерео, SFX — моно. Качество: эмбиент q2, музыка q3, фразы и SFX q4.
- **Петли бесшовны по построению.** Рендер круговой: хвосты нот, реверберация, эхо и фильтры заворачиваются из конца в начало. Частоты дронов и LFO подогнаны к целому числу периодов на петлю (`loop_hz`). Длина петли — ровно целое число тактов, до сэмпла.
- **Длина OGG проверяется по гранулам Ogg** (их читает Godot): совпадение до сэмпла, иначе сборка падает. Там же проверяются стык (`seam_ratio` ≤ 1,5) и пик после кодирования.
- **Детерминизм:** случайность только через `rng(seed)`, кодирование `bitexact`. Повторная сборка с нуля даёт те же байты (D-033).
- **Импорт в Godot:** у петель (`music_*`, `amb_*`, `sfx_reel_loop`) включить `Loop` в настройках импорта, `loop_offset = 0`. Остальные звуки без петли. Файлы `.import` создаёт редактор, их коммитит пользователь.
- **Вес:** пробный набор — 4,27 МБ OGG. Трек локации из трёх слоёв при q3 весит около 3,3 МБ, эмбиент около 0,7 МБ. Общий бюджет звука утверждается на Э8.1.

## 10. Конвейер
Запуск из корня `lunnyi_ulov/` (нужны python3, numpy, scipy, ffmpeg с libvorbis и libmp3lame):
```
python3 tools/audio/build_audio.py                  # собрать всё из реестра
python3 tools/audio/build_audio.py sfx_cast amb_    # по ID или префиксу (группа музыки собирается целиком)
python3 tools/audio/build_audio.py --list           # реестр
python3 tools/audio/preview.py                      # сценарии прослушивания → MP3 в tools/audio/_render/previews
```
- **Новый звук:** функция в партитуре `tools/audio/scores/<score>.py` → `render(part, seed)` → запись в `audio_assets.json` (`id`, `kind`, `bus`, `score`, `part`, `seed`, `loop`, `channels`, `ogg_q`, `norm`, `out`, `status`) → сборка → проверка по `report.md`.
- **Сценарии прослушивания** (`preview_scenarios.json`) сводят готовые OGG так, как их смешает AudioDirector: петли с нуля, громкость по точкам, приглушение, события поверх. MP3 нужны только для прослушивания и в репозиторий не входят: они лежат в Pod `previews/audio/`.
- `tools/audio/_render/` (WAV, отчёт, превью) — временная папка, в `.gitignore`.
