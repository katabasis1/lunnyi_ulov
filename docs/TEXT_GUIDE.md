# TEXT GUIDE — тексты в игре

## 1. Обязательное очеловечивание
- Каждый русский текст в игре (UI, подсказки, описания существ, реплики, лор, тексты для каталога Яндекса) проходит правила **humanizer-ru**: `docs/text/vendor/humanizer-ru_SKILL.md` (источник: github.com/Vladimir-Human/humanizer-ru).
- Каждый английский текст — правила **humanizer**: `docs/text/vendor/humanizer-en_SKILL.md` (источник: github.com/blader/humanizer).
- Порядок: написать → проход по таблице признаков навыка → вычитка вслух (ритм) → запись в `localization/strings.csv` → отметка в `docs/text/TEXT_LOG.md`.
- Русский — исходный язык. Английский пишется заново по смыслу, не дословно, затем проходит humanizer.

## 2. Чего не бывает в наших текстах
- Пустые подводки, «не просто X, а Y», тройки по шаблону, концовки-мораль, пафос, канцелярит, кальки («погрузиться в», «вызовы»).
- Тире вместо запятой и двоеточия (грамматическое тире — можно).
- Эмодзи, сленг ради живости, жирный как украшение.
- Тексты о самих себе («В этом окне вы можете…»).

## 3. Голоса
| Кто | Как звучит | Пример |
|---|---|---|
| Интерфейс | Коротко, глагол в начале, без восклицаний | «Закинуть», «Продать всё», «Корзина полна» |
| Подсказки | Одно действие, одна фраза | «Зажми и отпусти, чтобы закинуть» |
| Волшебник Ирвен | Мало слов, сухой юмор, усталость старика | «Клюёт. Или мне снова кажется» |
| Гном Брук, скупщик | Болтлив, торгуется, ворчит, но добрый | «Опять мелочь? Ладно, давай. Не пропадать же» |
| Призрак Эльса | Медленно, обрывки памяти, без пафоса | «Ключ от южной башни. Я его искала. Долго» |
| Описания существ | 1–2 фразы: конкретная деталь + странность | «Светится, только когда на неё не смотрят. Рыбаки спорят, правда ли это» |

## 4. Типографика
- Русский: кавычки «ёлочки», внутри „лапки“; буква «ё» везде, где она есть; грамматическое тире — с пробелами.
- Английский: прямые кавычки, без длинного тире как универсальной связки.
- Числа: пробел между разрядами (12 500), «см» и «кг» без точки.

## 5. Запреты по правилам Яндекс Игр
Не используем слова и образы чёрной магии (ритуал, проклятие, некромант, демон, жертва), религии (храм, молитва, святой, крест, монах), крови и жестокости, реальной политики и войн.
Вместо «проклятые воды» — «тёмные воды», «тихие воды»; вместо «заклятие» — «чары» только в бытовом смысле («чары на фонаре давно выдохлись»).
